# E2 — Bot age no grupo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** No grupo, "bot o PIX de 50 pro Fulano é mercado" ou "bot põe 150 de dentista nas contas" vira uma proposta; com "sim" de quem pediu (≤ 5 min) o worker grava pelas funções do painel; "bot desfaz" reverte (≤ 24 h).

**Architecture:** O modelo ganha 3 ferramentas: `buscar_lancamentos` (leitura) e `propor_categoria` / `propor_conta_avulsa`, que **só criam uma proposta** em `financas_bot_acoes`. Essas três rodam no worker (guardam refs `L1..L5` e propostas). A confirmação ("sim/não/número/desfaz") é lida por código antes do agente. A gravação e o desfazer são rotas do painel (`/api/bot/executar`, `/api/bot/desfazer`) que só aceitam proposta `confirmada`, usando `salvarRegra`/`criarMarca`/`apagarMarca` do F4/contas.

**Tech Stack:** Next.js 14, TypeScript, `pg`, Vitest 3, worker esbuild/Node 20.

**Spec:** `docs/superpowers/specs/2026-10-12-e2-bot-acoes-design.md`

## Global Constraints

- Branch `feat/e2-bot-acoes` (base `feat/e1-bot`, PR #17).
- O modelo nunca grava; nenhuma ferramenta de escrita no schema. "sim/não/número/desfaz" lidos por código.
- Confirmação: só quem pediu, ≤ 5 min. Desfazer: só o próprio, ação `feita` há ≤ 24 h. Uma proposta pendente por pessoa (nova substitui: `substituida`).
- "sim/não/número" sem "bot" só passam quando a pessoa tem proposta ou lista pendente; fora disso, ignorados sem log.
- Categoria só de `CATEGORIAS_PAINEL`; escopo `este|pessoa|texto` → `lancamento|doc|texto`; avulsa: valor 0,01–100.000, mês atual ou próximo, pessoa Matheus/Ariane (padrão: quem pediu).
- Textos de lista, proposta, feito, cancelado, expirado e desfeito são montados pelo sistema (um emoji por linha no começo; link `/gastos` ou `/contas` no fim do "feito").
- Sem telefone/JID/CPF no banco, log ou repo. Arquivos LF; editar com as ferramentas de edição (não Python em modo texto, não `node -e` com escapes).
- Testes de integração: `TEST_DATABASE_URL=postgres://postgres:teste@127.0.0.1:55432/personal_hub_db`, um arquivo por vez, banco recriado antes.

```ts
// E2: propostas do bot. Quem confirma é o código (UPDATE condicional = um "sim" vale uma vez só).
import type { Pool } from 'pg';

const JANELA = "interval '5 minutes'";

export class PgAcoes {
  constructor(private readonly pool: Pool) {}

  /** Nova proposta; a pendente anterior da mesma pessoa vira 'substituida'. */
  async criar(pessoa: string, tipo: 'categoria' | 'avulsa', params: object, resumo: string): Promise<number> {
    await this.pool.query(`UPDATE financas_bot_acoes SET estado = 'substituida', atualizado_em = now() WHERE pessoa = $1 AND estado = 'pendente'`, [pessoa]);
    const r = await this.pool.query(
      `INSERT INTO financas_bot_acoes (pessoa, tipo, params, resumo) VALUES ($1, $2, $3, $4) RETURNING id`,
      [pessoa, tipo, JSON.stringify(params), resumo]);
    return Number(r.rows[0].id);
  }

  /** A proposta pendente mais recente da pessoa nos últimos 30 min; `expirada` se passou de 5 min. */
  async pendente(pessoa: string) {
    const r = await this.pool.query(
      `SELECT id, tipo, params, resumo, criado_em <= now() - ${JANELA} AS expirada FROM financas_bot_acoes
       WHERE pessoa = $1 AND estado = 'pendente' AND criado_em > now() - interval '30 minutes' ORDER BY id DESC LIMIT 1`, [pessoa]);
    const x = r.rows[0];
    if (!x) return null;
    if (x.expirada) await this.pool.query(`UPDATE financas_bot_acoes SET estado = 'expirada', atualizado_em = now() WHERE id = $1`, [x.id]);
    return { id: Number(x.id), tipo: x.tipo, params: x.params, resumo: x.resumo, expirada: x.expirada as boolean };
  }

  async confirmar(id: number): Promise<boolean> {
    const r = await this.pool.query(
      `UPDATE financas_bot_acoes SET estado = 'confirmada', atualizado_em = now()
       WHERE id = $1 AND estado = 'pendente' AND criado_em > now() - ${JANELA} RETURNING id`, [id]);
    return (r.rowCount ?? 0) > 0;
  }

  async cancelar(id: number): Promise<void> {
    await this.pool.query(`UPDATE financas_bot_acoes SET estado = 'cancelada', atualizado_em = now() WHERE id = $1 AND estado = 'pendente'`, [id]);
  }

  async ultimaFeita(pessoa: string) {
    const r = await this.pool.query(
      `SELECT id, resumo, tipo FROM financas_bot_acoes WHERE pessoa = $1 AND estado = 'feita' AND atualizado_em > now() - interval '24 hours'
       ORDER BY atualizado_em DESC LIMIT 1`, [pessoa]);
    return r.rows[0] ? { id: Number(r.rows[0].id), resumo: r.rows[0].resumo, tipo: r.rows[0].tipo } : null;
  }
}
```

```ts
// E2: grava e desfaz as ações confirmadas pelo bot, com as mesmas funções das telas.
import { writerPool } from './db';
import { mesLabel, traduzCategoria } from './format';
import { apagarMarca, apagarRegra, categoriaDaRegra, alvoDaRegra, criarMarca, salvarRegra } from './queries';

type R = { ok: true; resumo: string; afetados?: number } | { ok: false; erro: string };
const brl = (v: number) => v.toLocaleString('pt-BR', { style: 'currency', currency: 'BRL' });

async function marcar(id: number, estado: string, resultado: unknown) {
  await writerPool.query(`UPDATE financas_bot_acoes SET estado = $2, resultado = $3, atualizado_em = now() WHERE id = $1`, [id, estado, JSON.stringify(resultado)]);
}

export async function executarAcao(id: number): Promise<R> {
  const { rows } = await writerPool.query(`SELECT tipo, params, estado FROM financas_bot_acoes WHERE id = $1`, [id]);
  const a = rows[0];
  if (!a) return { ok: false, erro: 'Ação não encontrada.' };
  if (a.estado !== 'confirmada') return { ok: false, erro: `Ação em estado ${a.estado}.` };
  try {
    if (a.tipo === 'categoria') {
      const p = a.params;
      const alvo = await alvoDaRegra(p);
      if ('erro' in alvo) { await marcar(id, 'erro', alvo); return { ok: false, erro: alvo.erro }; }
      const anterior = await categoriaDaRegra(alvo.tipo, alvo.chave);
      const r = await salvarRegra(p);
      if ('erro' in r) { await marcar(id, 'erro', r); return { ok: false, erro: r.erro }; }
      await marcar(id, 'feita', { regraId: r.id, afetados: r.afetados, anterior: anterior?.categoria ?? null });
      return { ok: true, afetados: r.afetados, resumo: `${r.afetados} lançamento(s) → ${traduzCategoria(p.categoria)}` };
    }
    const p = a.params;
    const marcaId = await criarMarca({ mes: p.mes, contaId: null, responsavel: p.responsavel, nome: p.nome, valor: p.valor, pago: false });
    await marcar(id, 'feita', { marcaId });
    return { ok: true, resumo: `${p.nome} ${brl(p.valor)} nas contas de ${mesLabel(p.mes)}` };
  } catch (e) {
    await marcar(id, 'erro', { erro: e instanceof Error ? e.message : String(e) });
    return { ok: false, erro: 'Não consegui gravar.' };
  }
}

export async function desfazerAcao(id: number, pessoa: string): Promise<{ ok: true } | { ok: false; erro: string }> {
  const { rows } = await writerPool.query(
    `SELECT tipo, params, resultado FROM financas_bot_acoes WHERE id = $1 AND pessoa = $2 AND estado = 'feita' AND atualizado_em > now() - interval '24 hours'`,
    [id, pessoa]);
  const a = rows[0];
  if (!a) return { ok: false, erro: 'Nada para desfazer.' };
  if (a.tipo === 'categoria') {
    // havia regra antes: regrava a categoria anterior; não havia: apaga a regra (volta ao banco ou a outra regra)
    if (a.resultado.anterior) await salvarRegra({ ...a.params, categoria: a.resultado.anterior });
    else await apagarRegra(a.resultado.regraId);
  } else {
    await apagarMarca(a.resultado.marcaId);
  }
  await writerPool.query(`UPDATE financas_bot_acoes SET estado = 'desfeita', atualizado_em = now() WHERE id = $1`, [id]);
  return { ok: true };
}
```

```ts
const brl = (v: number) => v.toLocaleString('pt-BR', { style: 'currency', currency: 'BRL' });
const MESES = ['jan', 'fev', 'mar', 'abr', 'mai', 'jun', 'jul', 'ago', 'set', 'out', 'nov', 'dez'];

export const NADA_DESFAZER = '🤷 Nada para desfazer nas últimas 24 h.';

export function lerResposta(texto: string): 'sim' | 'nao' | 'desfaz' | { numero: number } | null {
  const t = texto.trim().toLowerCase().replace(/[.!?]+$/, '');
  if (/^(sim|s|confirma|confirmo|pode|ok)$/.test(t)) return 'sim';
  if (/^(n[aã]o|n|cancela|cancelar)$/.test(t)) return 'nao';
  if (/^(desfaz|desfazer)$/.test(t)) return 'desfaz';
  if (/^[1-5]$/.test(t)) return { numero: Number(t) };
  return null;
}

export function textoLista(itens: { ref: string; data: string; valor: number; descricao: string; pessoa: string; categoria: string }[]): string {

}
```
